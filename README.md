# 表格数据提取工具

这是一个用于提取Excel表格中数据的工具，特别适用于处理检查结果和处理建议数据。

## 功能特点

- 支持同时上传多个Excel文件
- 自动提取检查日期、被检查单位、检查结果和处理建议
- 智能识别多种日期格式，包括日期范围
- 能够正确处理合并单元格
- 生成统计数据，包括问题数、纳入考核次数和检查站次
- 支持导出合并后的数据为Excel表格

## 使用说明

### 本地运行方式

1. 确保你的计算机上安装了Node.js
2. 打开命令行，进入项目目录
3. 运行以下命令启动本地服务器：

```
node server.js
```

4. 打开浏览器，访问 http://localhost:3000

### 移动端打包说明

如果需要在移动设备上使用，可以：

1. 使用WebView应用打包成APK
   - 可以使用WebView封装工具，如WebView2APK等
   - 将整个项目文件夹作为资源包含进应用
   - 确保主页设置为index.html

2. 使用PWA方式
   - 在支持的服务器上部署
   - 添加manifest.json文件
   - 用户可以将网页添加到主屏幕

### 使用流程

1. 点击上传区域或拖拽文件到上传区域上传Excel文件
2. 上传完成后，点击"开始处理"按钮
3. 系统会自动提取数据并显示处理结果
4. 点击"下载合并表格"按钮可以下载合并后的Excel文件

## 日期提取说明

系统能够识别以下日期格式：

1. 年份日期范围格式：
   - "2025年3月10日-3月16日"
   - "2025年3月10日-3月16日（票务专项检查）"
   - "3月10日-3月16日(2025年)"
   - "2025年3月10日至16日"（同月不同日）

2. 标准日期范围格式：
   - "3月10日-3月16日"
   - "3.10-3.16"

3. 单个日期格式：
   - "3月15日"
   - "3.15"
   - "后堡（3.4）"

对于日期范围，系统会优先使用结束日期（较晚的日期）作为检查时间。

## 常见问题

如果在移动设备上使用时出现"xlsx is not defined"错误，这可能是由于移动浏览器对本地文件的限制。最新版本已添加自动恢复功能，会尝试从CDN重新加载库。如果仍然不工作，请尝试以下解决方案：

1. 确保设备有网络连接
2. 清除浏览器缓存后重试
3. 尝试使用不同的浏览器（建议使用Chrome或Firefox）
